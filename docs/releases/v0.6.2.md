# nodectl v0.6.2 — WARP 默认配置与 DNS 回滚优化

发行包由 GitHub 发布工作流构建，完成 SHA256 清单签名和来源证明验证后公开。安装时必须验证官方签名。

本版本重点修复并优化核心网络配置与 DNS 部署生命周期：

1. **WARP 与网络出口标准默认配置**：
   - 将先前被作为可选/缺省略去的 `cn_warp`（独立 TUN 接口 `warp-cn`、路由表 5271、fwmark 5271、geodata 锁定路径）与 `web_services`（LibreSpeed 测速与 OpenList 文件站）完整纳入标准模板 `node.example.toml`，默认设为 `enabled = true`。
   - 快速配置工具 `nodectl setup` 增加 `--cn-warp`、`--web-services`、`--distribution` 选项，交互式模式下默认确认开启；`--warp` 不再强制默认 false。
   - 部署向导自动提示接受 Cloudflare WARP 注册条款时，默认预设值从 `"false"` 调整为 `"true"`，避免向导流程中因直接回车而意外阻断。

2. **DNS 记录创建与回滚保留机制优化**：
   - 优化 `restore()` 异常回滚处理：部署失败时，对修改过的旧记录继续执行还原，对**新创建的节点 DNS 记录默认安全保留**在 Cloudflare 上（不发送 DELETE 销毁），彻底解决“创建 DNS 后因后续环节超时/报错直接将其删除并陷入反复创建-删除恶性循环”的问题。
   - 提供 `--delete-dns-on-failure` 选项，供需要显式清理新建 DNS 记录的高级场景使用。
   - 再次重试部署时，程序自动识别并复用 Cloudflare 上已有的匹配 DNS 记录，无需重复创建或重置传播计时。

3. **公网 DNS 探测多解析器容灾与进度提示**：
   - `dns::verify` 增加多公共解析器轮询列表（`1.1.1.1`、`8.8.8.8` 及系统默认解析器），只要主流解析器之一或本机解析器确认解析匹配即放行，避免因单一公共 DNS 被运营商拦截或命中 300 秒 NXDOMAIN 负缓存而超时。
   - `dig` 探测重试次数由 1 次提升至 2 次，吸收偶发 UDP 丢包。
   - 未配置 IPv6 时跳过 AAAA 强制空比对，避免因外部缓存残留阻塞部署。
   - `dns::wait` 在等待期间每隔 15 秒输出当前耗时与具体等待的域名状态，提升运维透明度。
