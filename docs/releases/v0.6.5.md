# nodectl v0.6.5 — 修复 ACME IPv6 端口复用与双栈启动

## 问题与修复

1. **ACME 验证套接字 TIME_WAIT 导致 Nginx 无法启动**：
   - 在进行 Let's Encrypt IP 证书 HTTP-01 验证时，IPv6 ACME listener 未配置 `SO_REUSEADDR`/`SO_REUSEPORT`，验证连接主动关闭后套接字进入 `TIME_WAIT`（60秒）。
   - 导致后续应用阶段 Nginx 启动时在 `[::]:80` 报错 `Address already in use`。
   - 修复：显式为 IPv6 ACME 临时套接字配置 `SO_REUSEADDR` 与 `SO_REUSEPORT`，挑战完成后主动关闭连接并第一时间显式 drop 释放 80 端口。

2. **IPv6 规范化（RFC 5952）**：
   - 针对用户输入的含前导零 IPv6 地址（如 `2001:19f0:0000:...`），自动规范化转换为 RFC 5952 标准格式，确保符合 Let's Encrypt Boulder CA 与 Cloudflare API 的规范校验。

3. **服务状态与接管容错**：
   - 交互向导接管提示默认设置为 `true`，用户回车即可接管；
   - 增强 `service_state` 对 systemd 单元状态（`bad`、`masked` 等）的容错，避免在异常回滚阶段因查询状态报错中断。
