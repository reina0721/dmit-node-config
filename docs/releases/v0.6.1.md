# nodectl v0.6.1 — 仓库更名后的安装器修复

发行包由 GitHub 发布工作流构建，完成 SHA256 清单签名和来源证明验证后公开。安装时必须验证官方签名。

修复一键安装中断的问题。仓库所有者由 `i0721` 更名为 `reina0721` 后，GitHub 把 `releases/latest` 重定向到新所有者，安装器按字面前缀比对旧地址，因此在下任何下载之前就以 `Unexpected latest-release redirect` 退出。安装器现同时接受新旧所有者路径下的 `/releases/tag/` 重定向。

签名验证的信任边界没有放宽。清单仍按精确标签验签：当前身份为 `reina0721/dmit-node-config`，只有 v0.6.0 及更早的标签额外接受更名前签发、证书不可变的 `i0721` 身份；v0.6.1 起一律只认当前身份，避免旧用户名被他人注册后冒充发行。发行时会打印实际接受的签名者，便于核对。

内部版本号递增到 0.6.1，以便发行工作流用当前身份对清单签名，并使新版本能够校验自己的发行清单；其余行为与 v0.6.0 相同。README、`Cargo.toml`、`SECURITY.md`、安装与部署文档中的仓库地址已更新为 `reina0721/dmit-node-config`，旧链接由 GitHub 重定向，建议尽快更新书签与流水线中的地址。

Web 管理后台、自动部署向导、升级与回滚路径不变，见 [安装与管理](../web-admin-design.md)。
