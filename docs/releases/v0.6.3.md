# nodectl v0.6.3 — 修复官方 Xray 资产锁定版本与下载容错

发行包由 GitHub 发布工作流构建，完成 SHA256 清单签名和来源证明验证后公开。安装时必须验证官方签名。

本版本重点修复上游 Xray 依赖下载失败的问题：

1. **修正 Xray 官方锁定版本**：
   - 将 `versions.lock.toml` 中不存在的 `v26.10.10`（官方 GitHub 无此标签，请求返回 HTTP 404）更新为官方最新稳定版本 `v26.10.21`。
   - 重新计算并锁定官方编译产物的 SHA256 摘要：
     - amd64: `0eec3ed4163c273d8c8bf821f7d219e257921cf584aa3fb970715e458e631978`
     - arm64: `d1304946c486d98e6b886e9b931eaaaebb23835b30e217638037b7f2721d4e9c`
   - `src/config.rs` 密钥生成验证动态读取锁定版本，消除写死版本号校验。

2. **下载网络容错与报错信息可见性**：
   - `artifacts::download_xray` 补充 `--proto-redir =https` 重定向支持与 `--connect-timeout 20` 超时保护，确保重定向至 GitHub CDN 正常完成。
   - `artifacts` 运行外部工具失败时输出具体错误输出，不再遮蔽信息（不再显示 `output withheld`），方便运维排查。
