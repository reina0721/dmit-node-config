# nodectl v0.6.4 — 修复 acme.sh 安装工作目录与已有证书复用

发行包由 GitHub 发布工作流构建，完成 SHA256 清单签名和来源证明验证后公开。安装时必须验证官方签名。

本版本重点修复 ACME 证书自动化安装与复用机制：

1. **acme.sh 安装工作目录修复**：
   - `acme.sh --install` 脚本假定当前工作目录为源码目录，以便执行 `cp "$PROJECT_ENTRY" ...`。之前直接使用全路径 `/bin/sh <source>/acme.sh` 调用，导致因找不到相对路径下的 `acme.sh` 而报 `cp: cannot stat 'acme.sh': No such file or directory`。
   - 新增 `long_command_in`，在执行安装时将当前工作目录显式切换到解压后的 `source` 目录，确保安装顺利完成。

2. **证书复用退出码容错（RENEW_SKIP）**：
   - `acme.sh --issue` 在目标域名已存在有效、未过期的正式证书且域名未变更时，会跳过重新签署并返回退出码 `2`（`RENEW_SKIP`）。
   - 之前仅接受退出码 `0`，导致在已有证书环境下重试部署被误报为失败。现已将退出码 `2` 视为成功跳过，直接进入后续证书安装和热重载流程。

3. **外部命令报错回显**：
   - 当 provisioning 外部命令失败时，输出标准输出与标准错误末尾行信息，不再遮蔽信息，运维排查一目了然。
